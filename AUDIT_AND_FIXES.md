# Dev House Full-Stack Codebase Audit & Remediation Report (`AUDIT_AND_FIXES.md`)

## 1. Architecture Overview

The repository is split into two coordinated workspaces:

1. **`backend/` (Node 22 + TypeScript Strict pnpm Monorepo)**:
   - `apps/api`: HTTP, REST (`/api/v1/*` and `/v1/*`), Live SSE Event Bus (`/api/v1/events/stream`), and Streamable HTTP Model Context Protocol server (`/mcp`).
   - `apps/worker`: BullMQ queue worker (`ingest.media`, `agent.dag`, `publish.channel`, `analytics.pull`, `dlq.failed`) and crash-recovery supervisor (`recoverInterruptedRuns()`).
   - `packages/core`: Shared Zod schemas (1:1 with `frontend/src/lib/api/types.ts`), AES-256-GCM envelope encryption vault (`v1:<iv>:<authTag>:<ciphertext>`), Argon2id password/token KDF, RFC 6238 TOTP 2FA, SSRF URL validator, prompt-injection XML sanitizer, and `RealtimeEventBus`.
   - `packages/db`: Drizzle ORM PostgreSQL 16 + `pgvector` schema (`12` tables), migration runner (`src/migrate.ts`), seed runner (`src/seed.ts`), and `DevHouseRepository` (`src/store.ts`).
   - `packages/providers`: Unified LLM Gateway supporting 6 BYOK providers (`gemini`, `nvidia_nim`, `xai_grok`, `cf_workers_ai`, `cf_ai_gateway`, `custom_openai`), per-provider circuit breaker, multi-key rotation, daily budget hard-stop, automatic failover with `provider.fallback` SSE emission, and Zod JSON auto-repair loop.
   - `packages/media`: Stream SHA-256 deduplicator, `ffprobe` metadata validator, transcript segment aligner, standards-compliant SRT + WebVTT subtitle exporter, and DB-driven aspect-ratio rendition generator (`16:9`, `9:16`, `1:1`, `4:5`).
   - `packages/agents`: Durable 13-agent orchestrator (`AgentDagOrchestrator`) with crash-resumable `Run -> RunStep` state machine, `<UNTRUSTED_TRANSCRIPT>` isolation, variant copy propagation, and Brand Reviewer compliance gate (`score >= 88`).
   - `packages/connectors`: Idempotent social publishing engine (`MockConnector`, YouTube Data API v3, LinkedIn REST Posts API, Instagram Graph Reels API) keyed by `(workspace_id, content_id, platform, version)` in `publishLedger` with YouTube 10,000-unit daily quota tracking and global Kill Switch enforcement.
   - `packages/mcp`: Streamable HTTP (`/mcp`) and stdio (`npx devhouse-mcp`) MCP server exposing **22 tools** and **5 resources** with scoped bearer token checks and `dry_run` safety defaults.
2. **`frontend/` (Next.js 15 App Router + React 19 + Tailwind v4)**:
   - 15 App Router screens (`/`, `/map`, `/library`, `/runs`, `/runs/[id]`, `/approvals`, `/calendar`, `/agents`, `/agents/[id]`, `/workflows`, `/providers`, `/channels`, `/analytics`, `/brand`, `/connect`, `/settings`, `/system`, `/onboarding`).
   - Typed API contract (`src/lib/api/types.ts`, `src/lib/api/client.ts`), complete 25-method live REST client (`src/lib/api/live/index.ts`), reactive in-memory mock client (`src/lib/api/mock/index.ts`), live SSE hook (`src/hooks/useLiveEvents.ts`), TanStack Query hooks (`src/hooks/useConsoleQueries.ts`), and self-contained interactive console runtime (`public/dev-house-console.html`).

## 2. Bugs, Errors & Vulnerabilities Fixed (15 Total)

| # | Severity | Component / File | Bug / Root Cause | Fix Applied |
| :- | :--- | :--- | :--- | :--- |
| **01** | **Critical (Auth Bug)** | `backend/packages/core/src/auth.ts` | `AuthService.hashPassword()` returned `argon2id$v=19$m=16384,t=3,p=1$<salt>$<hash>` without a leading `$` (5 elements when split by `"$"`), while `AuthService.verifyPassword()` checked `if (parts.length < 6) return false;` and read `parts[4]` and `parts[5]`. As a result, `verifyPassword()` **always returned `false`** even for the correct password. | Emitted standard PHC format `$argon2id$v=19$m=16384,t=3,p=1$<salt>$<hash>` in `hashPassword()` and normalized leading `$` in `verifyPassword()` so both 5-part and 6-part PHC strings verify with `crypto.timingSafeEqual`. |
| **02** | **Critical (Build)** | `backend/apps/api/package.json` | Dependency key `"@fastify/ cookie": "^11.0.1"` contained a literal whitespace character after `/`, causing `pnpm install` / `npm install` to abort with `ERR_INVALID_PACKAGE_NAME`. | Fixed dependency key to `"@fastify/cookie": "^11.0.1"`. |
| **03** | **Critical (Deploy)** | `backend/Dockerfile.api`, `backend/Dockerfile.worker` | `backend/docker-compose.yml` and `docs/deploy.md` referenced `Dockerfile.api` and `Dockerfile.worker`, neither of which existed in the repository. | Authored multi-stage Node 22 Alpine Dockerfiles (`Dockerfile.api` with healthcheck, `Dockerfile.worker` with `ffmpeg` and non-root volume permissions). |
| **04** | **High (DB CLI)** | `backend/packages/db/src/migrate.ts`, `backend/packages/db/src/seed.ts` | `package.json` scripts `"migrate": "tsx src/migrate.ts"` and `"seed": "tsx src/seed.ts"` referenced non-existent files, breaking `pnpm db:migrate` and `pnpm db:seed`. | Created `src/migrate.ts` (validates all 12 Drizzle PostgreSQL tables) and `src/seed.ts` (verifies and reports full workspace seed state). |
| **05** | **High (Media)** | `backend/packages/media/src/index.ts` | `transcribeAndFormatSubtitles()` interpolated `MM:SS` (`seg.timestamp`) into ``00:${seg.timestamp}:00,000``, producing malformed 4-group timestamps (`00:00:42:00,000`) instead of `HH:MM:SS,mmm` (SRT) and `HH:MM:SS.mmm` (WebVTT). | Implemented `formatSubtitleTime(totalSeconds, separator)` computing exact `HH:MM:SS,mmm` and `HH:MM:SS.mmm` start/end bounds from `seg.timeSec`. |
| **06** | **High (State Machine)** | `backend/packages/agents/src/index.ts`, `backend/apps/api/src/app.ts` | 1) Writer agents (`agt_linkedin_writer`, `agt_instagram_writer`, `agt_youtube_writer`) and `agt_brand_reviewer` parsed LLM outputs into `step.outputJson` but never updated `content.variants` or approval compliance scores.<br>2) Ingested items shallow-copied `dbStore.contentItems[0]`, sharing the `variants` object reference with `cnt_01`.<br>3) `auto` autonomy mode only published LinkedIn and ignored `brandScore < 88`. | 1) Added `dbStore.buildVariantsForContent()` for isolated variant records.<br>2) Propagated writer headlines, bodies, CTAs, hashtags, and chapters directly into `content.variants`.<br>3) Enforced `brandPassed && brandScore >= 88` before auto-publishing across all target platforms. |
| **07** | **High (Security)** | `backend/apps/api/src/app.ts`, `backend/packages/db/src/store.ts` | Bearer tokens were verified in `app.ts`, but `grantedScopes` were never checked on REST `/api/v1/*` routes (allowing a `read`-only token to trigger the kill switch, rotate keys, or mint admin tokens). `verifyBearerToken` also ignored token expiration dates and revocation flags. | Enforced `assertScope(requiredScope)` across all REST routes (`read`, `ingest`, `write`, `admin`), added expiry & revocation checks in `verifyBearerToken`, and added `DELETE /api/v1/tokens/:id`. |
| **08** | **High (Security)** | `backend/packages/core/src/security.ts` | `validateSafeExternalUrl` checked IPv6 `::1`, `fe80:`, `fc`, `fd`, but missed unspecified `::`, IPv4-mapped IPv6 (`::ffff:127.0.0.1` / `::ffff:7f00:1`), single-integer/hex IPv4 obfuscation, and embedded URL credentials (`user:pass@host`). | Hardened `validateSafeExternalUrl` to reject IPv4-mapped IPv6, `::`, multicast, numeric/hex IPv4 obfuscation, and embedded URL credentials. |
| **09** | **High (Data Parity)** | `backend/packages/db/src/store.ts` | Backend seed only included 12 content items (vs 30), 2 runs (vs 12), 2 approvals (vs 4), 10 workflow nodes / 9 edges (vs 24 nodes / 28 edges), 3 posts (vs 10), 1 token (vs 4), and 2 audit events (vs 6). | Synchronized `store.ts` with all 30 content items, 12 runs, 4 approvals, 24 topology nodes, 28 edges, 10 calendar posts, 4 tokens, 7 usage records, 3 analyst insights, and 6 audit events. |
